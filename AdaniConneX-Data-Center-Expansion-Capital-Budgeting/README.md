# AdaniConneX Data Center Expansion Capital Budgeting Analysis

## Project Overview

This project evaluates the financial feasibility of AdaniConneX's proposed Data Center Expansion from 51 MW operational capacity to 1 GW by 2030.

The analysis applies capital budgeting techniques including:

- Net Present Value (NPV)
- Internal Rate of Return (IRR)
- Payback Period
- Profitability Index (PI)
- WACC Sensitivity Analysis

---

## Business Context

AdaniConneX, a joint venture between Adani Enterprises and EdgeConneX, is expanding its hyperscale data center infrastructure to capitalize on:

- AI & GenAI demand growth
- Cloud computing expansion
- Data localization regulations
- India's digital infrastructure gap

---
